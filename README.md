# Credit Intelligence Dashboard - ICBC

Dashboard de inteligencia crediticia para simular el trabajo de un analista senior de riesgo de cartera.

## Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Recharts
- lucide-react

## Modulos principales

- Resumen ejecutivo
- Calidad de cartera
- Ciclo de vida del cliente
- Limites de riesgo
- Rentabilidad
- Segmentacion
- Alertas e insights

## Ejecucion local

```bash
npm install
npm run dev
```

La aplicacion queda disponible normalmente en:

```text
http://127.0.0.1:5173
```

## Validacion

```bash
npm run build
```

El dataset es mock y esta definido en `src/data/mockData.ts`.
